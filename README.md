# برنامه هواشناسی امین — بخش مرکزی دزفول (Android / Jetpack Compose)

اپلیکیشن بومی اندروید (Kotlin + Jetpack Compose + Material 3) برای پیش‌بینی همرفتی و چندمدلی هواشناسی در بخش مرکزی دزفول.

## ویژگی‌ها
- **واکشی مستقیم از Open-Meteo**: دریافت داده‌های ساعتی سه مدل مستقل (`GFS`، `ECMWF`، `ICON`) و احتمال‌های Ensemble.
- **موتور تحلیل همرفتی (`ForecastEngine`)**: وزن‌دهی هوشمند مدل‌ها، میانه مقاوم بارش، کالیبره بایاس، شاخص صاعقه و پتانسیل همرفتی.
- **کالیبراسیون دقیق احتمال بارش (PoP)**: تطبیق احتمال انسمبل با رطوبت نسبی سطح زمین و پوشش ابر، و حذف احتمالات کاذب در ساعات بدون بارش.
- **تفکیک بارش محتمل از بیشینه رگبار همرفتی**: نمایش همزمان «بارش محتمل (mm)»، «سقف پتانسیل رگبار (mm)» و «توصیف وضعیت بارش».
- **کارت تحلیل ۲۴ ساعته بارش**: خلاصه تحلیلی، بازه محتمل و تفکیک پیش‌بینی مدل‌های ECMWF، GFS و ICON.
- **تقویم شمسی (جلالی) و راست‌به‌چپ (RTL)**: تبدیل تاریخ میلادی به شمسی با الگوریتم Borkowski و نمایش ارقام فارسی.
- **نمودارهای بومی Compose Canvas**: نمودار روند دما و بارش، و نمودار احتمال بارش و امتیاز صاعقه.
- **بازه‌های زمانی متنوع و جدول قابل‌شخصی‌سازی**: ساعتی، ۶ ساعته، ۱۲ ساعته، یک روزه، سه روزه و یک هفته به همراه انتخاب ستون‌های جدول.
